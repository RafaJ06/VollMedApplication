# VollMedApplication
 En este repositorio muestro como desarrollo una aplicación Java siguiendo las formaciones de Alura Latam + Oracle llamadas: 

Spring Boot 3: desarrolla una API REST en Java

Spring Boot 3: aplique las mejores prácticas y proteja una API Rest

Spring Boot 3: documentar, probar y preparar una API para su implementación. 

Dividiré el proyecto en 3 fases, con su respectiva rama cada una:

Primera rama (fase): La creación de los RestControllers y validaciones.
Segunda rama (fase): Agregamos seguridad y login a nuestro proyecto.
Tercera rama (fase): Agregamos documentación, test automaticos y unitarios y algunas reglas de negocio.
